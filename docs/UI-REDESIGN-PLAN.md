## 0. 为什么要做

现有 UI 是「程序员审美」：全默认控件、深灰底、无卡片、无图标、无导航、所有功能堆一屏。
**结论：功能有了，外观需要向成熟启动器（PCL2/HMCL）看齐，并套上明日方舟的视觉皮肤。**

## 2. UI 设计目标

**PCL2 的结构骨架 + 明日方舟的视觉语言。**

### 2.1 明日方舟 UI 视觉语言提炼（务必照此还原）

| 元素 | 规格 | 实现 |
|---|---|---|
| 底色 | 深灰黑 `#1b1c1e` / `#232427`（**非纯黑**），卡片分两层灰 | 背景 + 卡片 |
| 主强调色 | **荧光青绿** `#00e5c0` ~ `#2ee6a8`（罗德岛色） | 按钮 / 高亮 / 进度条 |
| 辅色 | 警示橙黄 `#ffb400` / 危险红 | 状态徽章 |
| 字体 | 无衬线、窄、全大写拉丁 + 粗黑中文（系统字体加粗替代，版权字体不打包） | TextView 加粗 + 字距 |
| **标志性几何** | **斜切角**（按钮/卡片一角 45° 斜切）+ **细边框线** | 手写 `Path` / `GradientDrawable` |
| 装饰 | 左上角小方框、角标、`//` 分隔线、编号 `01` `02` | TextView 拼接 |
| 质感 | 半透明玻璃、扫描线 / 网格、HUD 感 | 多层 Drawable 叠加 |

> **一句话记忆：斜切角 + 细线框 + 荧光绿，三件套 = 一看就是明日方舟。**

### 2.3 舟味细节清单

- 区块标题：`▌` 竖色条 + 标题 + 右侧灰色编号 `01/02/03`
- 卡片：深灰底 + **左上角斜切** + 1px 半透明青绿边框
- 按钮：主按钮 = 荧光绿实心（黑字）；次按钮 = 透明底 + 青绿描边
- 分隔线：文本装饰线 `// SYSTEM LOG`
- 可选：底部极细扫描线 / 网格背景，营造 HUD 感

## 3. 技术方案

**零依赖纯手写 Drawable**（不用 Material、不用 Compose）。

**理由**：Material 的「圆角 + 阴影」与舟的「硬朗斜切」气质冲突，套上去反而不像；手写 Path/GradientDrawable 还原度更高。Compose 依赖太重（APK +几十 MB、编译慢），排除。

### 3.1 新增文件：`app/src/main/java/com/stronghold/shell/UiKit.kt`

```kotlin
object UiKit {
    // 颜色
    val BG_DEEP   = 0xFF1B1C1E
    val BG_CARD   = 0xFF232427
    val ACCENT    = 0xFF00E5C0   // 罗德岛青绿
    val ACCENT_D  = 0xFF2EE6A8
    val WARN      = 0xFFFFB400
    val TEXT_HI   = 0xFFE6EDF3
    val TEXT_LO   = 0xFF7D8590

    fun slantedBg(color: Int, cut: Int): Drawable        // 斜切角背景
    fun arkButton(ctx, text, primary: Boolean): Button    // 舟味按钮
    fun arkCard(ctx) { ... }: LinearLayout                // 斜切角卡片容器
    fun sectionHeader(ctx, index: String, title: String)  // ▌ 标题 01
    fun dot(color: Int): View                             // 状态点
    fun divider(ctx, label: String)                       // // SYSTEM LOG
}
```

### 3.2 重写 `ImportActivity.kt` 的 `buildUi()`

功能逻辑（导入 / 启动 / 删除 / mod 管理）**保持不变**，只替换 View 的构建方式。

### 3.3 硬编码颜色集中到 UiKit

现在 `ImportActivity` 里到处是 `Color.parseColor("#0d1117")`，全部改用 `UiKit.XXX`，为将来主题切换铺路。

## 4. 工作量与风险

| 内容 | 预估 |
|---|---|
| `UiKit.kt` 样式工具集 | 1.5–2 h |
| 重写 `ImportActivity` 布局 | 2 h |
| 斜切角 Drawable 真机调试 | 1 h |
| 颜色 / 字体微调 | 1 h |
| **合计** | **约 5–6 h**（1 轮编译 + 1–2 轮真机微调） |

**风险**：
1. ⚠️ 斜切角靠代码画，**无法先出效果图**，只能「写完 → 编译 → 装机 → 看 → 调」，预计 **2–3 轮迭代**。
2. ⚠️ 明日方舟实际字体（思源黑体等）**有版权不能打包**，用系统默认字体加粗替代，视觉还原度**约打 8 折**。
3. ⚠️ 手机端编译一圈十几分钟，**效率低** → 优先交电脑端（dsh）。

## 5. 分三期规划（每期独立可用）

### 第一期：视觉重构（不新增功能，只改外观）⭐ 先做
- `UiKit.kt` + 重写 `buildUi()`
- 圆角/斜切卡片、自定义按钮、图标（emoji 或矢量）、状态徽章
- **风险最低、不破坏现有功能、改完立刻可编译验证**

### 第二期：结构与导航（拆页）
- 底部导航：**主页 / 版本 / 设置 / 日志**
- 版本页 = 未来「下载原版 / Forge」的落点（**为 0.3.0 预留**）
- 设置页 = 端口、启动参数、清缓存
- 日志页 = 完整日志（现在只显示 300 字）

### 第三期：进阶功能
- mod 列表改 RecyclerView 卡片（图标 + 开关）
- 下载管理器（进度条 + 断点续传）
- 主题切换（深 / 浅）
